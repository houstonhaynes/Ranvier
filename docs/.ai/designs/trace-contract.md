# Trace contract: design record

**Status:** implemented for [#166](https://github.com/shayanhabibi/Ranvier/issues/166) on `issue/166`. The plan is
`docs/superpowers/plans/2026-10-24-issue-166.md`; the user-facing description is the "Node identity" and
"Machine-readable diagnostics" sections of `docs/content/guide/tracing.md`. Consumers: #168 (MCP spike) and #65
(event sourcing).

## Core and view state

**Core primitives used:** the `TraceLog` and its checkpoint (`Trace.fs`) supply the retained events and the folded
prefix; `TraceModel.fold` supplies graph state; `TraceModel.why`, `whyNot`, `waitingOn` and `history` supply
provenance; `TraceModel.dumpText` and `parseDump` supply the dumps.

**View-owned state:** none. All code is traced-only core code.

## Shape

- `src/Ranvier/TraceModel.fs` holds `TraceScalar` and `TracePayload`, because `TraceDump.Payloads` needs them.
- `src/Ranvier/TraceContract.fs` (traced only, after `TraceModel.fs`) holds the codecs (`TraceCodec`,
  `TraceCodecs`), identity (`TraceNodeRef`, `TracePathStability`, `TraceAddress`, `TraceLookup`), the state and run
  projections (`TraceGraphState`, `TraceNodeState`, `TraceRunState`, `TraceWhy`, `TraceWhyStep`), the
  `TraceContract` functions over a checkpoint and events, and `TraceJson`: Fable-compatible writers and .NET-only
  readers.
- `src/Ranvier/TraceApi.fs` adds the graph-taking entry points: `Trace.lookup`, `lookupNode`, `state`, `runs`,
  `whyWith`, `dumpTextWith` and `lastSeq`.
- `src/Ranvier.CSharp/Tracing.fs` returns the documents as JSON text and builds codecs from delegates, following
  `csharp-tracing-access.md`: C# receives text, never option-bearing records.

## Decisions

- **No new identity API.** A fully labelled path is the persisted identity (`Named`); a path with a site segment is
  `Located`. A key API would duplicate `Trace.named`.
- **No graph discriminator in a ref.** Every graph's root owner id is 1, and a process-unique id would make fixtures
  depend on run order. `TraceNodeRef.Graph` was removed.
- **Reuse provenance records where they hold no `obj`.** `WhyNotReason` and `TraceWaiting` are reused as they are.
  `WhyStep.Value` and `TraceRun.Value` are `obj option`, so `Why` and `TraceRun` are projected to `TraceWhy` and
  `TraceRunState` with `TracePayload` values.
- **Qualified projection records.** `TraceRunState`, `TraceWhy` and `TraceWhyStep` repeat the labels of the records
  they project and are declared later, so an unqualified `TraceRun` literal would infer the projection.
  `RequireQualifiedAccess` keeps the existing literals' types; a projection literal qualifies its first label.
- **Lossy by default, strict on request.** Most payloads have no codec, and a failing dump is unusable during
  development. `TraceCodecs.strict` gives the failure a replay consumer needs.
- **Ambiguous log entries are marked, not guessed.** A null `Moved` payload is the value for a memo, async memo or
  boundary (`Null`), carries no value for a projection (`None`), and is ambiguous for a lookup cell, which records a
  null value and a suspension alike (`Lossy "null"`).
- **A folded null is recorded.** `TraceModel.fold` gives a node `Value = Some (valueText null)` for a null `Write` and
  for a null `Moved` of a memo, async memo, boundary or lookup cell, so a checkpoint holds the null rather than the
  earlier value, and `state` reads it as `Lossy "null"`. `history` keeps skipping null moves.
- **Schemas 1 and 2 untouched.** `Trace.dumpText` keeps its bytes; schema 3 payload forms are opt-in through
  `dumpTextWith`. Schema 1 and 2 payloads carry no type, so their text reads as `Lossy` and `parseDumpWith` keeps it
  as text: the text `1` of an `int`, a `float` or a `string` is the same.
- **Codec-taking dump functions live in `TraceContract`.** `TraceCodecs` is declared after `TraceModel`, so
  `dumpTextWith` and `parseDumpWith` are `TraceContract` functions over an internal `TraceModel.dumpTextEncoded`.
- **Readers are .NET only,** as `parseDump` is: they use `System.Text.Json`.

## Verification

- Pinned-text tests write every union case of each document (`TraceJsonTests.fs`, .NET and Fable), and readers round
  trip them (.NET).
- Committed fixtures in `tests/Ranvier.Tests/fixtures/trace` pin dump schemas 1, 2 and 3 and one document per kind;
  each is regenerated byte for byte and read back (`TraceDumpTests.fs`, `TraceFixtures.fs`).
  `tools/trace-fixtures.fsx` rewrites them.
- The FsCheck property "a checkpointed graph's state, documents and lookups answer as its twin's"
  (`TraceCheckpoints.fs`) checks checkpoint semantics over random programs and splits.
- A reflection test asserts no contract type holds an `obj`, `INode` or mutable field.

## Open

- A pending memo records the default value of its type in its `Moved` payload, so its state value reads as, for
  example, `Exact (Int 0)` beside a `Pending` status. The status is the authority; the payload is not marked.
- `Trace.runs` reports a run that moved to null with `Value = None`, as `TraceModel.history` does, because the history
  carries no node kind.
