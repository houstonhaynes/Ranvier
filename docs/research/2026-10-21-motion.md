# Motion: anime.js 4.5.0 probes and the Fable binding shape

Date: 2026-10-21. Spec: `docs/superpowers/specs/2026-10-21-motion-design.md`. This note records step 1 (the Fable 5.18.0
probe) and the anime probes the spec was written from, and the rulings taken while building `src/Fable.Ranvier.Anime`
(step 2). Every number below was measured on anime 4.5.0 from npm, Fable 5.18.0, Node 26.7.0 and jsdom 30.1.1.

## Fable 5.18.0 probe

The probe compiled one file with Fable and with `dotnet build` (net10.0, Fable.Core 5.3.0, Xantham.Fable.Core.TS 0.2.1):
an `[<Erase>]` `Value` with `op_Implicit` from `float`, `int` and `string`; an `[<Erase>]` `Ease` with inline string
members, an `[<Emit>]` member and `[<Import; ParamObject>]` members; an `[<Erase>]` `Anime` with an `[<Import>]` static
member; and `type Anim [<ParamObject; Emit("$0")>] (...)` with 40 optional arguments.
`src/Fable.Ranvier.Anime` now holds the same shapes with 61 arguments on `Anim`.

| Question | Result |
|---|---|
| `[<ParamObject; Emit("$0")>]` constructor, ~45 optional arguments | Works. Emits an object literal with the given arguments only, in **constructor declaration order**, not call order. Transform order is unaffected: anime composes transforms in a fixed order (perspective, translations, rotations, scales, skews). |
| `op_Implicit` on named optional arguments (`x = 100`, `y = "50%"`, `scale = 0.9`) | Works, int, float and string. No warning. |
| `op_Implicit` on a lambda's return (`Value.per (fun _ i n -> i * 10)`, `modifier = fun v -> v * 2.`) | Rejected: FS0001 "The type 'int' does not match the type 'Value'". F# converts at method arguments only. |
| `[<Import>]` static member of an `[<Erase>]` type | Works: `import { animate } from "animejs"` and a direct call. |
| `[<Import; ParamObject(1)>]` (`Value.stagger (20, start = 100)`) | Works: `stagger(20, { start: 100 })`; with no options `stagger(20, {})`. |
| `[<Emit("($0[$1]=$2,$0)")>]` instance member (`.With`) | **Wrong output**: `$0` is the object literal, emitted twice, so the call receives a second literal without the property. |
| `int array`/`float array` arguments (`[| 1; 2 |]`) | Emitted as `Int32Array`/`Float64Array`, which anime's `Array.isArray` tests reject: a stagger's `from` falls back to `first`, `snap` returns `NaN`, a draggable's bounds are read as a selector. Array parameters emit `[$0, $1]` or `[$0...]`. |
| .NET compile of the same file | Builds, 0 warnings. |
| .NET evaluation of `Anim(x = 1)` with `op_Implicit` as `unbox` | Raises `InvalidCastException` (a `Double` is not a `Value`). |

Emitted call sites (`fable/Ranvier.Anime.Tests/Fixtures.fs` and `Surface.fs`, Release, abridged):

```js
import { spring as spring_1, createTimeline, stagger, animate } from "animejs";

animate(el, { x: 1 });
animate(el, { x: 100, opacity: [0, 1], duration: 400, ease: "outQuart" });
animate(el, { y: "50%", rotate: {from:45}, scale: 0.9, delay: stagger(20, { start: 100 }) });
animate(el, { x: 1, modifier: (v) => (v * 2), onComplete: (_arg) => { log("done"); } });
animate(el, Object.assign(({ duration: 300 }), {["--hue"]: 120}));
(createTimeline({ autoplay: false }).add(el, ({ x: 1 }), ('+=' + 50))).label("end");
animate(el, { x: 1, ease: spring_1({ stiffness: 200 }) });
waapi_1.animate(el, parameters);         // Waapi.animate, through the imported `waapi` object

```

The binding files with only erased, imported or emitted members (`Values.fs`, `Tickables.fs`, `Anime.fs`) emit no
module. `Params.fs` emits an empty class and a reflection function per parameter type, which a bundler drops when
unused; `Reactive.fs` and `Testing.fs` emit their functions. None holds `curry`, `uncurry`, `partialApply` or
`createObj` (checked by `fable/Ranvier.Anime.Tests/emit.test.mjs`).

## anime probes

Copied from the spec author's scratch probes (`anime-clock/clock.test.mjs`, `flash.test.mjs`, `anime-size/size.mjs`).

**Manual clock.** anime evaluates `isBrowser` and binds `now = Date.now` when the module is first evaluated, so a test
sets the DOM globals and calls `mock.timers.enable({ apis: ["Date"], now: 1000 })` before a dynamic `import()` of
anything importing `animejs`. Then `engine.useDefaultMainLoop = false`, `engine.pauseOnDocumentHidden = false`, and per
step `mock.timers.tick(ms); engine.update()`:

```js
mock.timers.enable({ apis: ["Date"], now: 1000 });
const A = await import("animejs");
A.engine.useDefaultMainLoop = false; A.engine.pauseOnDocumentHidden = false;
const anim = A.animate(el, { opacity: [0, 1], translateX: 100, duration: 1000, ease: "linear" });
for (let t = 0; t <= 1000; t += 250) { mock.timers.tick(t === 0 ? 0 : 250); A.engine.update(); }
// opacity at 0, 250, 500, 750, 1000 ms: "0", "0.262", "0.512", "0.762", "1" (every run)
```

Each read runs 12 ms ahead of the mocked time: `Timer.resume ()` sets `this._startTime -= 12` to force a frame on the
next tick (`timer/timer.js`), and every autoplaying tickable resumes on creation. The checks read 0.512 at 500 ms,
51.2 px and 46.08° at 500 ms of `x: 100, rotate: 90`, and 0.62 for the second of three targets staggered by 100 ms at
150 ms, and assert these exact values.

**jsdom.** `animate`, `utils.set`, `revert`, `createAnimatable`, `createTimeline` and `createLayout(...).record()` run.
`splitText`, `onScroll` and `createDraggable` throw without `ResizeObserver` and `DOMPoint`/`DOMMatrix`; jsdom has no
`el.animate`, so WAAPI and the layout's transform animation do not run.

**Initial render.** `animate(a, { opacity: { from: 0 } })` writes `opacity: 0` before any tick; `[0, 1]` with a delay
writes nothing until the delay passes. `complete()` renders the end value; `cancel()` keeps the current inline styles.

**Callbacks.** `then()` resolves with `undefined`. A replacing animation's `complete()` read `opacity 0` in the probe
(spec risk 5, unsettled).

`Anime.animate (el, Anim(x = 100, opacity = Value.fromTo (0, 1), duration = 400, ease = Ease.outQuart))` against the

committed copy.

## Rulings

Ruling: `.With` emits `Object.assign($0, {[$1]: $2})` — the spec's `($0[$1]=$2,$0)` evaluates the literal twice under
Fable 5.18 and drops the property — cost if wrong: one `Object.assign` call per `.With`.

Ruling: the erased types convert through `Erased.cast`, `unbox` under Fable and `Unchecked.defaultof` on .NET — with
`unbox`, evaluating `Anim(x = 1)` or `LayoutParams(duration = 350)` on .NET raises, and portable templates build parts
at definition time — cost if wrong: one hidden public module. `[<Emit>]` and `[<Import>]` members (`Value.stagger`,
`Value.from`, `Ease.spring`, `Ease.outBackBy`, `At.after`) still raise on .NET when evaluated, so portable code calls
them inside hooks.

Ruling: `modifier` parameters are `float -> float`, not `float -> Value` — F# applies `op_Implicit` only at method
arguments, so `fun v -> v * 2.` would not type-check — cost if wrong: a string-returning modifier needs
`.With ("modifier", ...)`. `Value.per` keeps `-> Value`; its function converts with `Value.op_Implicit`.

Ruling: interface members carry anime's JavaScript names (`play`, `progress`, `setX`, `record`), not the spec's
PascalCase — each PascalCase member would need its own `[<Emit>]` — cost if wrong: a rename of every tickable member.

Ruling: the files compile in the order `Values.fs`, `Tickables.fs`, `Params.fs`, and the members taking parameters
(`Timeline.add/addTimer/set`, `AutoLayout.animate/update`) are type extensions in `Params.fs`'s auto-opened
`TickableParams` module — parameter callbacks are typed by the tickables and those members are typed by the
parameters — cost if wrong: the members resolve only with `Ranvier.Anime` opened.

Ruling: the DOM types are written `TS.Dom.Element` and the binding files do not open `Fable.Core.TS.Dom` — that
namespace's `Animatable` and `Text` shadow the bindings' own in any file that opens it — cost if wrong: none at call
sites; a consumer opening `Fable.Core.TS.Dom` after `Ranvier.Anime` sees the DOM's `Animatable` and `Text`.

Ruling: `Reactive.own` outside every root registers with the graph's own scope instead of raising — the public API
cannot tell the graph's scope from a root — cost if wrong: an animation owned at top level reverts at graph disposal.

Ruling: `Engine` exposes the imported `engine` object as `Engine.settings` plus `Engine.update ()` — F# static
properties with inline setters over an import are more code for the same emit — cost if wrong: `Engine.settings.speed`
instead of `Engine.speed`.

Ruling: `Scope.add` takes `Scope -> unit` — `Scope -> (unit -> unit)` emits `uncurry2` — cost if wrong: a constructor
cannot return its own cleanup; anime reverts the objects the constructor created with the scope.

Ruling: the bindings tests live in `fable/Ranvier.Anime.Tests`, the repository's place for Fable-compiled suites — the
spec's `examples/Ranvier.Motion/tests` arrives with step 10, and `build.fsx` treats every project under `src/` as a
source project — cost if wrong: one move into the examples app.

Ruling: `Fable.Ranvier.Anime` is not packable and targets net10.0, as `Fable.Ranvier` — Xantham.Fable.Core.TS 0.2.1,
the DOM types the view uses, is published on the xantham feed only, so a nuget.org consumer could not restore the
package — cost if wrong: projects reference it by `ProjectReference` until Xantham 0.2 reaches nuget.org.

Ruling: grid stagger origins are `StaggerFrom.at (x, y)`, fractions of the grid in 0..1 — anime 4.5 reads an array
`from` as `from[0] * (grid[0] - 1)` — cost if wrong: a rename. `Grid.size (columns, rows)` and `Grid.auto` replace the
`int array` grid.

Ruling: `At.afterPrevious` is `"<"` (the end of the previous child) and `At.withPrevious` is `"<<"` (its start) — the
spec's `At.withPrevious` for `"<"` read as simultaneous while anime places the child sequentially — cost if wrong: a
rename at each timeline call site.

Ruling: `Value.per` passes the target, its index and every target — anime calls a function value as
`(target, index, targets, prevTween)` — cost if wrong: a count-taking variant needs a wrapper lambda.

Ruling: `Reactive.track` restores a callback slot only while it still holds the chain — a slot assigned after `track`
keeps its callback — cost if wrong: a later assignment chained before disposal stops seeing the earlier callbacks.

Ruling: `Reactive.policy` keeps one signal per graph in a `WeakMap` (`ConditionalWeakTable` on .NET) and removes its
media-query listener in a cleanup on `graph.Root` — cost if wrong: a first call inside a pure derivation raises, as
`onCleanup` does.

Ruling: the committed `docs/research/motion/bindings-bundle.json` is checked for drift by the CI `anime` job — the
numbers are cited above — cost if wrong: a bundler or anime upgrade fails the job until the JSON is regenerated.

Ruling: these 4.5.0 parameter forms are left out of the types — the function forms of `ScrambleParams`' `text`,
`chars`, `duration`, `revealDelay` and `delay`, of `Value.stagger`'s `use`, and of `DraggableParams`' numeric options;
`DraggableParams.containerPadding` as an array; `SpringParams.onComplete` (the animation's `onComplete` covers it);
`Utils.get` on JS-object targets returning a number (`Utils.getNumber` reads it) — cost if wrong: `.With` or a new
member per form.
